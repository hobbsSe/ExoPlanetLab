# Reference runs, for run_batch.py: one job
# per line, a name then KEY=VALUE settings (EXOPLANETLAB_* variables, prefix
# optional); '#' starts a comment. Anything not set here takes the defaults in
# ExoPlanetLab.py (isotropic orientation prior for emcee/nessai, tempered joint
# fit, 100 tau stop, Student-t noise for epoch data, orbit-corrected
# parallax for masses) -- so SOURCE_MODE is always set explicitly, in case the
# default in the script has been edited.
#
#   python3 Tools/run_batch.py Tools/jobs_reference.txt --dry-run
#   python3 Tools/run_batch.py Tools/jobs_reference.txt
#
# 19 jobs, longest first so that the batch packs well on 9 cores.
# The astrometric noise model is set in every job: Student-t for the DR4
# sources (the default for epoch data), Gaussian for the simulated benchmark
# and the jitter validation (whose point is the jitter). Only the DR4 jobs:
#   python3 Tools/run_batch.py Tools/jobs_reference.txt --only '^(Gaia|HD)'
